# Indicator methodology and confidence

The indicator layer provides context beside policy records. It does not claim
that a policy caused a measured change.

## Confidence rubric

Confidence describes the evidence available for the normalized series, not the
importance of the indicator or the quality of the publishing institution.

- **High** — an official source publishes a defined table or dataset with clear
  units, periods, and revision or provisional markers. Normalization requires
  little interpretation.
- **Medium** — an official source publishes the values and labels, but the
  denominator, field dictionary, revision practice, coverage, or extraction
  method is incompletely documented.
- **Low** — the official evidence is a snapshot, changes definition across
  periods, uses a proxy broader than the dashboard label, or requires material
  interpretation. The limitation must be visible beside the values.

## Comparison rules

- Do not connect observations across a known definition change.
- Use one shared scale for series shown as comparable in the same group.
- Show the period, unit, latest value, and full raw table.
- Missing observations are not zero.
- Subscriptions, accounts, transactions, devices, and people are distinct
  measures.
- Publication dates and reference periods must not be conflated.
- Provisional and revised observations retain their source status.

## Verification layers

The release distinguishes:

1. the source URL was opened;
2. source metadata and an exact locator were reviewed;
3. normalized observations passed the data contract; and
4. the series is current as of the visible snapshot date.

No one layer implies the others.
